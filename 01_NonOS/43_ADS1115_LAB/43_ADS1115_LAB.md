# 43. 정밀 외장 ADC — ADS1115

## 목표

`07`에서 쓴 ESP32-S3 내장 ADC(12bit, 비선형성 있음)보다 훨씬 정밀한 **16비트 I2C ADC**를 다룹니다. 정밀 측정이 필요한 센서(로드셀, 정밀 온도 등)를 쓸 때 내장 ADC 대신 흔히 선택하는 부품입니다.

## 준비물

- ADS1115 모듈

## 회로

- `09`와 동일 I2C 배선 (SDA=GPIO8, SCL=GPIO9), 주소 보통 `0x48`
- 측정할 아날로그 신호(예: `07`의 가변저항 wiper) → ADS1115의 A0

## 라이브러리 설치

```ini
lib_deps =
    adafruit/Adafruit ADS1X15 @ ^2.5.0
```

## 코드

```cpp
#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_ADS1X15.h>

Adafruit_ADS1115 ads;

void setup() {
  Serial.begin(115200);
  delay(1000);
  Wire.begin();

  if (!ads.begin()) {
    Serial.println("ADS1115 not found - check wiring");
    while (1) delay(1000);
  }
}

void loop() {
  int16_t raw = ads.readADC_SingleEnded(0);   // 채널 0 (A0)
  float volts = ads.computeVolts(raw);

  Serial.printf("raw=%d  voltage=%.4fV\n", raw, volts);
  delay(200);
}
```

## 실행 & 확인

- 가변저항을 돌리면서 `raw`(16비트, -32768~32767 범위이지만 단일 종단 입력은 0~32767만 사용) 값과 `voltage`가 정밀하게 변하는지 확인
- `07`(내장 ADC, 12비트=4096단계)과 비교해보면, 같은 전압 변화에도 `raw` 값의 변화 폭이 훨씬 촘촘한(16비트=65536단계) 것을 확인할 수 있습니다

## 관찰 포인트

- 내장 ADC와 정밀 외장 ADC 중 뭘 쓸지는 트레이드오프입니다 — 내장 ADC는 배선 추가 없이 바로 쓸 수 있지만 정밀도가 낮고 비선형성이 있습니다. ADS1115는 I2C 배선이 추가로 필요하지만, 훨씬 정밀하고 **프로그래머블 게인 앰프(PGA)**로 측정 범위 자체를 조절할 수 있어 미세한 전압 변화도 잡아낼 수 있습니다
- `setGain()`으로 측정 범위를 바꿀 수 있습니다 — 기본값(`GAIN_TWOTHIRDS`)은 ±6.144V 범위지만, 더 좁은 신호(예: 센서가 0~1V만 출력)라면 `GAIN_SIXTEEN`(±0.256V)처럼 범위를 좁혀서 그 안에서의 분해능을 극대화할 수 있습니다
- ADS1115는 4채널(A0~A3)을 지원해서, `readADC_SingleEnded(1)`, `(2)`, `(3)`처럼 여러 아날로그 신호를 하나의 모듈로 동시에 다룰 수도 있습니다

## 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| `ADS1115 not found` | `09`의 스캐너로 `0x48`(ADDR 핀 상태에 따라 `0x49`~`0x4B`도 가능) 확인 |
| 값이 항상 최대치에 붙어 있음 | 입력 전압이 현재 게인 설정의 범위를 초과 — `setGain()`으로 범위를 넓히거나 입력 전압을 낮추기 |
