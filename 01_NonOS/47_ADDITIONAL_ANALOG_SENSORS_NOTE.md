# 47. 추가 아날로그 센서 참고 노트

아래 센서들은 `07_ADC_LAB.md`(가변저항 아날로그 읽기)와 **회로 구성과 코드가 사실상 동일**합니다. 별도 실습으로 만들기보다, "이런 센서들도 있고 지금까지 배운 패턴 그대로 쓸 수 있다"는 걸 정리해둡니다. 실제로 갖고 계신 모듈로 바로 대입해서 쓰시면 됩니다.

## 공통 패턴 (07번 재사용)

```cpp
#include <Arduino.h>

const int SENSOR_PIN = 1;   // 실제 사용하는 센서로 교체

void setup() {
  Serial.begin(115200);
  delay(1000);
}

void loop() {
  int raw = analogRead(SENSOR_PIN);
  float voltage = raw * (3.3f / 4095.0f);
  Serial.printf("raw=%d, voltage=%.2fV\n", raw, voltage);
  delay(200);
}
```

## 해당하는 센서들

| 센서 | 감지 대상 | 참고 사항 |
|---|---|---|
| **Water Level Sensor** | 수위(물에 잠긴 정도) | 노출된 전극 패턴에 물이 닿는 면적이 늘어날수록 저항이 낮아지는 원리 — `raw` 값이 클수록 수위가 높음. 장시간 물에 노출 시 전극 부식 가능성 있음 |
| **Soil Moisture Sensor** | 토양 수분 | Water Level과 원리가 유사(저항식) — 다만 흙에 직접 꽂는 센서는 부식 방지를 위해 커패시티브(정전용량) 방식 모듈을 권장. 이 경우도 출력은 동일하게 아날로그 전압 |
| **MQ-3** (알코올) | `45_GAS_SENSOR_MQ135_LAB.md`와 코드 동일, 감지 대상만 알코올 증기 |
| **MQ-7** (일산화탄소) | `45`와 코드 동일, CO 감지 — 다만 정확한 측정을 위해서는 가열/비가열 사이클을 반복하는 특수한 구동 방식이 데이터시트에 권장되어 있어, 정밀 측정이 필요하면 별도 확인 필요 |
| **GP2Y1010AU0F** (먼지/분진) | 다른 센서들과 달리 **내부 LED를 정확한 타이밍(약 0.28ms)에 맞춰 펄스로 켜야** 정상적인 측정값이 나오는 특수한 구동 방식 — 단순 `analogRead()`만으로는 안 되고, LED 구동 타이밍을 `delayMicroseconds()`로 맞추는 별도 코드가 필요합니다. 정확히 구현하려면 제조사 애플리케이션 노트(datasheet의 timing chart)를 참고하세요 |

## 관찰 포인트

- 이 센서들은 전부 "저항이나 전압이 물리량에 비례해서 변한다"는 같은 원리를 씁니다 — `analogRead()` → `map()` 또는 선형식으로 실제 단위(cm, %, ppm 등)로 환산하는 것도 똑같은 패턴입니다
- 정밀한 값이 필요하다면, `07`에서 언급했듯 내장 ADC 대신 `43_ADS1115_LAB.md`(16비트 외장 ADC)로 바꿔 끼우는 것도 코드 변경이 크지 않습니다 (`analogRead(pin)` → `ads.readADC_SingleEnded(channel)`)
