# 23. TM1637 모듈 (2-wire 7-Segment)

## 목표

74HC595(`21`)로 세그먼트 하나하나를 직접 제어하는 것과 달리, TM1637은 4자리 7-Segment 전체를 컨트롤러 칩이 내장된 모듈로 제공해서 **2개의 신호선(CLK, DIO)만으로 숫자를 표시**할 수 있습니다.

## 준비물

- TM1637 4자리 7-Segment 모듈

## 회로

- CLK → GPIO5
- DIO → GPIO4
- VCC → 3.3V(또는 5V, 모듈 사양 확인), GND → GND

## 라이브러리 설치

```ini
lib_deps =
    avishorp/TM1637Display @ ^1.2.0
```

## 코드

```cpp
#include <Arduino.h>
#include <TM1637Display.h>

#define CLK_PIN 5
#define DIO_PIN 4

TM1637Display display(CLK_PIN, DIO_PIN);

void setup() {
  display.setBrightness(0x0f);   // 0x00(어둡게) ~ 0x0f(밝게)
}

void loop() {
  static int counter = 0;

  display.showNumberDec(counter);   // 숫자를 4자리로 표시 (앞자리 0은 자동 생략)
  counter = (counter + 1) % 10000;
  delay(200);
}
```

## 실행 & 확인

- 0부터 9999까지 숫자가 0.2초 간격으로 증가하며 표시되는지 확인

## 관찰 포인트

- `21`(74HC595 직접 구동)과 비교하면 코드가 훨씬 간단합니다 — TM1637 칩 자체가 세그먼트 패턴 변환, 자릿수 스캔(4자리를 빠르게 순환 점등해서 잔상으로 동시에 켜진 것처럼 보이게 하는 방식) 등을 내부에서 처리해주기 때문입니다. "직접 제어(로우레벨, 자유도 높음)"와 "전용 컨트롤러 모듈(하이레벨, 사용 간편)"의 트레이드오프를 비교해볼 수 있는 좋은 사례입니다
- 시:분 표시(예: `12:34`)처럼 콜론을 넣고 싶다면 `showNumberDecEx()`에 콜론 플래그를 추가로 넘기면 됩니다 (라이브러리 예제 참고)
- `setSegments()`로 4자리 각각의 세그먼트 비트 패턴을 직접 지정할 수도 있습니다 — 숫자가 아닌 임의의 문자/패턴(예: "Err", "----")을 표시하고 싶을 때 유용합니다

## 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| 아무것도 표시 안 됨 | CLK/DIO 배선이 바뀌지 않았는지 확인 (반대로 연결해도 컴파일은 되지만 동작 안 함) |
| 밝기가 너무 어둡거나 밝음 | `setBrightness()` 값 조정 |
| 숫자가 깜빡임 | TM1637은 원래 스캔 방식이라 미세한 깜빡임이 있을 수 있음 — 정상적인 특성 |
