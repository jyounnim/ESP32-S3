# 44. 조도 센서 — BH1750

## 목표

주변 밝기를 실제 단위(lux)로 측정하는 I2C 조도 센서를 다룹니다. `07`의 CDS(광저항) 아날로그 방식과 달리, BH1750은 내부에서 이미 lux 단위로 변환해서 값을 줍니다.

## 준비물

- BH1750 모듈 (I2C 주소 보통 `0x23`)

## 회로

- `09`와 동일 I2C 배선

## 라이브러리 설치

```ini
lib_deps =
    claws/BH1750 @ ^1.3.0
```

## 코드

```cpp
#include <Arduino.h>
#include <Wire.h>
#include <BH1750.h>

BH1750 lightMeter;

void setup() {
  Serial.begin(115200);
  delay(1000);
  Wire.begin();

  if (!lightMeter.begin()) {
    Serial.println("BH1750 not found - check wiring");
    while (1) delay(1000);
  }
}

void loop() {
  float lux = lightMeter.readLightLevel();
  Serial.printf("Light: %.1f lux\n", lux);
  delay(500);
}
```

## 실행 & 확인

- 손으로 센서를 가리면 lux 값이 뚝 떨어지고, 밝은 곳으로 옮기면 값이 크게 올라가는지 확인 (참고: 흐린 날 실외 약 1000lux, 맑은 날 실외 수만 lux, 일반 실내 조명 100~500lux 정도)

## 관찰 포인트

- CDS(광저항) + ADC 조합은 "밝을수록 저항이 낮아진다"는 물리적 특성을 대략적인 상대값으로만 읽는 반면, BH1750은 센서 내부에 ADC와 변환 로직이 이미 들어있어 **실제 조도 단위(lux)로 보정된 값**을 바로 줍니다 — 정밀한 밝기 비교나 조명 자동화(예: 특정 lux 이하일 때 LED 켜기)에 훨씬 적합합니다
- `31`(센서→OLED 게이지)에서 만든 `drawGauge()` 함수를 재사용해서, 온습도 옆에 조도 게이지를 하나 더 추가하는 것도 좋은 응용 과제입니다
- BH1750은 연속 측정 모드 외에 1회 측정 모드(`ONE_TIME_HIGH_RES_MODE` 등)도 지원합니다 — 배터리 절전이 중요한 프로젝트라면 필요할 때만 측정하고 나머지 시간은 센서를 대기 상태로 두는 게 유리합니다

## 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| `BH1750 not found` | `09`의 스캐너로 `0x23`(ADDR 핀 상태에 따라 `0x5C`도 가능) 확인 |
| 값이 항상 0 | 센서가 완전히 가려져 있거나 배선 방향(전면/후면) 확인 |
